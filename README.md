# LIME — умная примерочная (демо-прототип)

Учебный MVP: сенсорный экран в примерочной (`/`) и панель консультанта (`/staff`).
Аватар — **имитация** (SVG-слои на силуэте), это прототип механики, а не настоящая виртуальная примерка.

## Требования
Node.js 20+

## Запуск
```bash
npm install && npm run seed && npm run dev
```
- Киоск: http://localhost:5173/?room=1 (комнаты 1–6; лучше открыть в окне формата 9:16)
- Консультант: http://localhost:5173/staff
- `npm run seed` — пересоздать данные (каталог, остатки, образы; очищает заявки)
- `npm run build` — сборка клиента; после неё сервер (`npm start --prefix server`) раздаёт всё на :3001

## Сценарий демо (2–3 минуты)
1. Открыть две вкладки: `/?room=3` и `/staff`.
2. На киоске: категория «Верхняя одежда» → «Пальто прямое шерстяное» (нажать на название) → размер M → «Принести в примерочную» → плавающая кнопка → «Отправить заявку».
3. На `/staff` сразу появляется карточка «Примерочная 3» (со звуком). «Принять» → «Принёс» — статус меняется на киоске.
4. Показать серые размеры (пальто XS, кроссовки 41), надеть несколько вещей, «Сохранить образ», поставить сердечко на вещи — она появится в нижней ленте рядом с образами; выбрать образы и/или вещи → «Заказать», выбрать размеры → «Отправить заявку».
5. «Позвать консультанта» → вызов на панели → «Иду» → «Готово».

## Принятые решения (где ТЗ неоднозначно)
- Товаров 26 (в таблице ТЗ их 26, а не 25).
- Аксессуары комбинируются между собой (у каждого своя «зона»), остальные зоны — одна вещь на зону; платье вытесняет верх и низ.
- «← Назад» снимает выбор категории и показывает весь каталог.
- Стартовый образ при загрузке и после 60 с бездействия: футболка, джинсы, кроссовки.
- `/api/staff/queue` отдаёт все заявки и вызовы, фильтр «активные/выполненные» — на клиенте.
- Статус `delivered`/`cancelled` необратим; в списке заявок киоска ничего дополнительно не рисуется — статусы показываются плашками.
- Проект на чистом JS (без TypeScript). Шрифт Manrope подгружается с Google Fonts (без сети — системный).
